# مدیر ارسال زمان‌بندی‌شده

این نمونه یک بنر را فقط به گروه‌هایی می‌فرستد که خودتان انتخاب کرده‌اید و حساب
در آن‌ها مدیر است. فاصلهٔ ارسال کمتر از ۱۰ ثانیه و فاصلهٔ دورها کمتر از ۳۰ دقیقه
پذیرفته نمی‌شود.

## اجرا

از ریشهٔ پروژه:

```bash
pip install -e .
python -m examples.broadcast_manager.app
```

اجرای مستقیم نیز پشتیبانی می‌شود:

```bash
python examples/broadcast_manager/app.py
```

فرمان `!help` را از حساب خودتان در «پیام‌های ذخیره‌شده» بفرستید. هم ارسال مستقیم
فرمان و هم ویرایش یک پیام قبلی به فرمان پشتیبانی می‌شود. برنامه ابتدا همان پیام را
به «در حال انجام» و سپس به نتیجهٔ نهایی ویرایش می‌کند.

نمونهٔ تنظیم:

```text
!banner جشنواره امروز؛ برای اطلاعات بیشتر پیام بدهید.
!groups count 5
!gap 20
!every 60
!start
```

برای استفاده از یک پیام کامل شامل عکس، فایل یا متن به‌عنوان بنر، روی آن پیام
ریپلای کنید، یک پیام عادی بفرستید و سپس پیام جدید را به `!banner` ویرایش کنید.

تنظیمات در `sessions/broadcast-settings.json` ذخیره می‌شوند و وارد Git نمی‌شوند.

قبل از ارسال، رضایت اعضا و قوانین بله و گروه را رعایت کنید. این نمونه قابلیت
عضویت خودکار، جمع‌آوری کاربر یا ارسال به گروه‌های بدون مدیریت شما ندارد.
