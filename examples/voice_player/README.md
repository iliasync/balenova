# پخش آهنگ و ویس در تماس بله

این نمونه از اطلاعات تماس دریافتی از بله و LiveKit برای فرستادن صدای واقعی به
تماس استفاده می‌کند. فایل ریپلای‌شده دانلود و با FFmpeg به صدای مناسب تماس تبدیل
می‌شود.

این مثال با Python 3.10 به بالا و LiveKit 1.1 به بالا اجرا می‌شود؛ نسخهٔ نصب‌شده
در محیط توسعه با Python 3.14 نیز بررسی شده است.

## پیش‌نیاز

```bash
pip install -e '.[voice]'
sudo apt install ffmpeg
```

## اجرا

```bash
python -m examples.voice_player.app
```

برنامه باید هنگام ارسال و ویرایش فرمان روشن باشد. ابتدا یک پیام معمولی از حساب
خودتان بفرستید و سپس آن را به فرمان زیر ویرایش کنید:

```text
!vc join 12345|2
```

بعد روی یک آهنگ یا ویس ریپلای کنید، پیام دیگری بفرستید و آن پیام را ویرایش کنید:

```text
!vc play
```

فرمان‌های `!vc pause`، `!vc resume`، `!vc stop`، `!vc status` و `!vc leave` نیز
به همین روش اجرا می‌شوند.

این بخش آزمایشی است؛ ساختار تماس با نسخهٔ فعلی وب بله و SDK رسمی LiveKit تطبیق
داده شده، اما تست زنده به حساب واقعی، گروه دارای تماس و FFmpeg نیاز دارد.
